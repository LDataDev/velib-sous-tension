# velib-sous-tension
À partir d'un jeu de données basé sur la disponibilité de 80 stations de Vélib' disponibles en temps réel, nous allons classifier l'état futur d'une station par différentes méthodes de machine learning et conserver la plus efficiente.

## Contexte
Dans le cadre d'un projet pour le cours de *Machine Learning / IA fiable* de monsieur [Christophe Ambroise](https://ambroise.cloud/), nous allons appliquer différentes méthodes de machine learning vues en cours, les comparer et conclure sur la meilleure méthode d'apprentissage dans ce contexte.
